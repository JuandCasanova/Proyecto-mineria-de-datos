# scripts/ — experimentación y extensiones

Prototipos y utilidades auxiliares que no forman parte del pipeline
CRISP-DM (las fases oficiales viven en `src/`). Aquí van pruebas de
modelos alternativos, consultas a APIs de datos de videojuegos
(Steam, IGDB, Metacritic) y experimentos sueltos antes de promoverlos
a una fase de `src/`.
